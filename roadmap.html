AniApp · Roadmap

Personal sideloaded anime app built on the ani-cli allanime scraper, ported to React Native + TypeScript.

Done Next up Later

v1 · Search & Play

Done

Minimum viable loop: find a show, pick an episode, watch it.

  • Port allanime GraphQL queries (search / episodes / sources) to TypeScript
  • Hex-pair URL decoder for provider source IDs
  • Provider resolution + /clock.json link extraction
  • React Navigation native stack: Search → Episodes → Player
  • HLS playback via react-native-video with Referer header

v2 · Sub/Dub + Quality picker

Next up

Surface ani-cli's existing knobs: pick translation, pick resolution.

  • Sub/Dub toggle on Search and Episodes screens (state lifted to a small store)
  • Parse wixmp multi-resolution URL pattern (,1080p,720p,…,/mp4/) into discrete qualities
  • Resolve master m3u8 → variant playlists; expose quality list to the player UI
  • Quality picker overlay in Player (Best / 1080 / 720 / 480 / Worst)
  • Persist preferred mode + quality in AsyncStorage

v3 · Continue watching & history

Later

Local-only tracking — no accounts, no backend.

  • Persist {showId, episodeString, positionMs, durationMs, watchedAt} per show
  • "Continue Watching" carousel on the Search screen
  • Resume playback from saved position; auto-mark watched at 90%
  • "Next Episode" affordance at end of current episode
  • Clear-history action in a small Settings screen
