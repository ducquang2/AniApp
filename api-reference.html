allanime API Reference

GraphQL schema notes for AniApp · captured via introspection

Used by the app today Needs an allanime account (auth) Not relevant to anime watching

Endpoint

Single GraphQL endpoint, POST with a JSON body of { query, variables }.

POST https://api.allanime.day/api

Headers:
  Content-Type: application/json
  User-Agent:   Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:109.0) Gecko/20100101 Firefox/121.0
  Referer:      https://allmanga.to
  Origin:       https://allmanga.to

Introspection is open — the full schema can be re-queried any time with { __schema { queryType { fields { name } } } }.

Anime — ready to use (no auth)

QueryReturnsArgsUse
showsused ShowsConnection search, page, offset, limit, translationType, countryOrigin, queryAt Search. Currently powers searchAnime().
showused Show _id, queryAt, search Single show. App only reads availableEpisodesDetail — far more is available (see Show type below).
episodeused Episode showId, episodeString, translationType, queryAt, search Stream sources. Powers getPlayableLinks(). Needs the persisted-query hash to skip the captcha gate.
fastSearch SearchResult search Lighter search variant — good for typeahead.
showsWithIds Show ids, search Batch-fetch shows by a list of IDs. Best fit for hydrating a local watchlist (store IDs, fetch fresh metadata).
episodes EpisodesConnection showId, translationType, episodeNumStart, episodeNumEnd, search Episode listing with a numeric range.
episodeInfos EpisodeInfo showId, episodeNumStart, episodeNumEnd, queryAt Per-episode metadata: thumbnails, description, notes, upload dates.
queryPopular RecommendationsResponse type, size, dateRange, isAdult, page, allowAdult, allowUnknown, denyEcchi Trending shows — a home/discover screen.
queryLatestPageStatus RecommendationsResponse pageSearch Recently-updated episodes feed.
queryRecommendation RecommendationsResponse pageSearch Recommendations.
queryRandomRecommendation AnyCard format, allowAdult, translationType, denyEcchi One random show — a "Surprise me" button.
queryTags TagsConnection search, page, offset, limit Genre/tag list.
queryListForTag TagListRecommendationsResponse search Browse shows within a tag/genre.
sameVoiceActorShows ShowsConnection staffAniListId, animeId, pageNo, limit, offset, allowAdult, allowUnknown, denyEcchi Shows sharing a voice actor.
characters CharactersResponse search, page, offset, allowAdult, allowUnknown, denyEcchi, limit Character info.

Caveat — introspection ≠ guaranteed working. A query appearing in the schema does not mean it returns data with plain headers. shows / show work with just the Referer headers; episode needed the persisted-query SHA-256 hash to dodge a captcha gate. Verify queryPopular, episodeInfos, and showsWithIds with a live request before building on them.
